## Project Description

This repository contains 10 Python case studies developed as part of the Activity-Based Learning (ABL) program. These programs help improve Python programming skills by solving practical problems using basic programming concepts, conditional statements, loops, calculations, and data handling.

Each case study focuses on a different problem and demonstrates how Python can be used to develop simple and useful solutions.
